# Landing Page de Vendas - Sistema de Cardápio & Catálogo Digital WhatsApp

Uma landing page moderna, de alta conversão e altamente otimizada desenvolvida para apresentar e vender a solução de **Cardápio Digital e Sistema de Pedidos Via WhatsApp**. Ideal para estabelecimentos de Gastronomia (hamburguerias, pizzarias, restaurantes), Lojas de Moda e Varejo em geral.

---

## 🎯 Finalidade do Projeto

Esta página tem como objetivo principal **converter visitantes em clientes** do sistema SaaS de catálogo digital. A estrutura foi construída utilizando as melhores práticas de UI/UX, psicologia de vendas e copywriting focado em conversão:

- **Proposta de Valor Clara:** Apresentação imediata dos benefícios de automatizar pedidos no WhatsApp sem comissões abusivas por pedido.
- **Demonstração Interativa:** Smartphone mockup interativo que permite alternar entre diferentes nichos (Gastronomia, Moda, Varejo) para visualizar o produto em ação.
- **Comparativo Antes vs Depois:** Visualização clara das dores operacionais (atendimento lento, erros de pedido) contra a eficiência automatizada do sistema.
- **Transparência de Preços & ROI:** Tabela de preço simplificada com cálculo de retorno sobre investimento (ROI).
- **Quebra de Objeções:** Seção dinâmica de Perguntas Frequentes (FAQ) em formato sanfona (accordion).
- **Atendimento Rápido:** Botão flutuante do WhatsApp e chamadas diretas para ação (CTAs).

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando uma stack moderna, rápida e responsiva para garantir tempos de carregamento ultra-rápidos e uma experiência visual fluida:

- **[React 18](https://react.dev/):** Biblioteca JavaScript para construção de interfaces reativas e baseadas em componentes.
- **[Vite 5](https://vitejs.dev/):** Ferramenta de build de nova geração que oferece HMR (Hot Module Replacement) extremamente rápido e bundler otimizado para produção.
- **[Tailwind CSS](https://tailwindcss.com/):** Framework CSS utility-first customizado com paleta Gradient Navy Blue, efeitos de glassmorphism e animações.
- **[Lucide React](https://lucide.dev/):** Biblioteca de ícones vetoriais modernos e leves.
- **[PostCSS](https://postcss.org/) & [Autoprefixer](https://github.com/postcss/autoprefixer):** Processamento CSS avançado para garantia de compatibilidade entre navegadores.

## 🚀 Como Configurar e Executar o Projeto

### Pré-requisitos

Certifique-se de ter instalado em sua máquina:
- **Node.js** (versão 18.0.0 ou superior recomendada)
- **npm** (gerenciador de pacotes incluso com o Node.js)

### 1. Clonar ou Baixar o Repositório

```bash
git clone <URL_DO_REPOSITORIO>
cd <NOME_DA_PASTA>
```

### 2. Instalar as Dependências

Execute o comando abaixo para instalar todas as bibliotecas necessárias:

```bash
npm install
```

### 3. Executar o Servidor de Desenvolvimento

Para iniciar o servidor local com recarregamento automático em tempo real:

```bash
npm run dev
```

A aplicação estará acessível em `http://localhost:5173` (ou no endereço fornecido no terminal).

### 4. Gerar o Build para Produção

Para otimizar e minificar o código para implantação em produção (Vercel, Netlify, Hostinger, etc.):

```bash
npm run build
```

Os arquivos estáticos otimizados serão gerados dentro da pasta `dist/`.
